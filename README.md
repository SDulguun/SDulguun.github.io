# sdulguun.github.io

Personal portfolio of **Dulguun Sukhchuluun**, Data Scientist / Data Analyst.

Live site: [sdulguun.github.io](https://sdulguun.github.io)

## About

A single-page portfolio built with plain HTML, CSS, and a touch of JavaScript. No frameworks, no build step, no dependencies. It introduces who I am, the skills I work with, projects I have shipped, and how to get in touch.

## Languages

The site is bilingual with a toggle in the top right:

- `index.html` — Mongolian (default landing page)
- `en.html` — English

Both pages share the same structure and content, translated.

## Sections

- **About** — short professional bio
- **Skills** — Python and SQL, machine learning and deep learning, statistical analysis, dashboarding
- **Projects** — five end-to-end projects covering credit risk modeling, an AI interview coach, PM2.5 forecasting, a deepfake detection benchmark, and a personal AI assistant
- **Contact** — email, GitHub, LinkedIn

## Tech

Vanilla HTML + CSS, no build tooling. Hosted on GitHub Pages from the `main` branch. The portrait image is embedded as base64 so the page is fully self-contained.
